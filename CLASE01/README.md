# 🌿 Propuesta Seleccionada: Pellets de Biomasa Mixtos (Vid + Tomate)

> **Energía Renovable y Acondicionamiento Agrícola para la Región de Mendoza**

### 🔴 El Problema

Las bodegas y conserveras de Mendoza generan miles de toneladas de escobajo de uva y descarte de tomate, afrontando altos costos para su disposición final como residuos. 

Paralelamente, los suelos agrícolas de la región presentan una severa disminución de materia orgánica y baja capacidad de retención hídrica, obligando a los productores a depender de fertilizantes sintéticos importados y abonos químicos de elevado costo.
